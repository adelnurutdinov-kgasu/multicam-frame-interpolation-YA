# Результаты и как они измерены

## Что сравнивается

| Обозначение | Что это |
|---|---|
| **RIFE** | нейросетевая интерполяция по двум кадрам одной камеры; геометрию сцены не использует. Baseline |
| **warp-mix** | геометрический перенос: глубина из LiDAR, кадры соседних камер в `t₀` и `t₁` переносятся в целевую камеру и смешиваются. Обучения нет |
| **consensus U-Net** | Partial-Conv U-Net, предсказывает `residual` поверх геометрического `base_init`: `pred = clamp(base_init + residual)`. Чекпоинт v2 |

## Метрики

**PSNR** = 10·log₁₀(1 / MSE) при значениях в [0, 1]. Стандартная метрика задачи.

**SSIM** — Wang et al. 2004, гауссово окно 11×11, σ = 1.5, C₁ = (0.01·255)², C₂ = (0.03·255)², по яркостному каналу.

**Резкость** — дисперсия лапласиана изображения, в процентах от того же значения для истинного кадра. Это не метрика качества, а индикатор: она отвечает на вопрос «не куплен ли PSNR замыливанием». Читать её надо осторожно в обе стороны:

- значение сильно ниже 100% означает потерю высоких частот, то есть мягкость;
- значение **выше** 100% означает не детали, а лишние высокие частоты — швы, дребезг на краях варпа, спекл от попиксельного голосования.

Дисперсия лапласиана очень чувствительна: гауссово размытие с σ = 1.5 px уже убирает около 98% её величины. Поэтому «резкость 1%» читается как «примерно σ ≈ 1.3–1.5 px размытия», а не как уничтоженная картинка.

## Почему сеть отдаёт резкость

Обучение идёт по MSE. Резкий, но сдвинутый на пиксель контур штрафуется дважды: и там, где контура быть не должно, и там, где его не хватило. Сглаженный ответ штрафуется один раз.

Формально: для пикселя, истинное значение которого не определено входами, оптимум MSE — условное среднее по правдоподобным вариантам, то есть размытие. Численный пример: пусть пиксель истинно равен 0 или 255 с вероятностью ½.

- Ответ 127.5: MSE = 127.5² = 16256 → PSNR = 10·log₁₀(65025 / 16256) = **6.02 дБ**
- Ответ 0 или 255 наугад: MSE = 255² / 2 = 32512 → PSNR = 10·log₁₀(65025 / 32512) = **3.01 дБ**

Ровно 3.01 дБ в пользу значения, которого в сцене не существует. Отсюда и поведение сети: она сглаживает там, где не уверена в геометрии, и это оптимальная стратегия под выбранную метрику, а не дефект обучения.

Обратная сторона: PSNR и SSIM не вознаграждают настоящую текстуру, которую даёт геометрия. Обе метрики штрафуют рассинхрон на пиксель сильнее, чем размытие. Для оценки текстурной достоверности нужна перцептивная метрика (LPIPS), она пока не считалась.

- Числа по сети получены на чекпоинте **v2**. Модели v3–v5 обучены, но их предиктов для этих сэмплов на диске нет.
