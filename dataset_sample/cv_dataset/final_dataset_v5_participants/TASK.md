# YAML Contest — Novel View Synthesis

## Задача

Дан датасет с данными проездов беспилотных автомобилей. Автомобиль оснащён **6 камерами** (фронтальная, задняя, 2 боковые передние, 2 боковые задние) и **лидаром**.

Для каждого сэмпла предоставлены:

| Данные | Описание |
|--------|----------|
| **12 изображений** | 6 камер × 2 момента времени (t0 и t1), разделённых на 1 или 2 секунды |
| **Плотное облако точек** | Агрегация всех лидарных свипов между t0 и t1 (~10–20 свипов), координаты в мировой системе |
| **Позы камер** | Матрицы 4×4 camera-to-world для всех 12 входных видов и целевого вида |
| **Интринсики камер** | fx, fy, cx, cy, width, height, коэффициенты дисторсии |

**Цель**: по 12 входным изображениям, облаку точек и позам — предсказать изображение с указанной камеры в промежуточный момент времени (≈ середина между t0 и t1).

**Метрика**: PSNR (Peak Signal-to-Noise Ratio) между предсказанным и GT изображением.

### lidar.npz

Плотное облако точек, собранное из лидарных свипов в расширенном окне вокруг `[t0, t1]`.
Временной диапазон агрегации — 3× длина интервала `delta`: один `delta` до `t0`, сам интервал `[t0, t1]`, и один `delta` после `t1` (с клампингом по границам проезда).

- `xyz` — координаты точек `(N, 3)`, float32, в мировой системе координат
- `intensity` — интенсивность отражения `(N,)`, float32

Типичный размер: 300k–1.5M точек (зависит от длительности интервала и окружения).

```json
    "left_fwd": {...}, "left_bwd": {...},
    "right_fwd": {...}, "right_bwd": {...}, "rear": {...}
```

Ключевые поля:
- `target_camera` — имя камеры, для которой нужно предсказать изображение
- `delta_s` — временной интервал между t0 и t1 (1.0 или 2.0 секунды)
- `poses_c2w` — матрицы camera-to-world 4×4 для каждой камеры в каждый момент
- `intrinsics` — параметры камер (одинаковые для t0, t1 и target одной камеры)

## Система координат

### Камеры (poses_c2w)
Матрицы 4×4 **camera-to-world**. Камерные оси — **OpenCV**:
- x → вправо
- y → вниз
- z → вперёд (в сцену)

### Мировая система (world frame)
Основана на позиции автомобиля в начальный момент сцены:
- x → вперёд (по ходу движения)
- y → влево
- z → вверх

### Лидар
Координаты `xyz` в `lidar.npz` — в **той же мировой системе**, что и позы камер.
Облако агрегировано из расширенного окна `[t0 − delta, t1 + delta]` (3× delta), с клампингом по границам проезда. Это даёт более плотное покрытие сцены.

Для каждого сэмпла из test-сплита — предсказанное изображение:

```
submission/
```

Изображение `pred.jpg` должно быть в формате JPEG, RGB, с тем же разрешением, что и GT (обычно 1920×1200 для фронтальной камеры, может отличаться для боковых).

## Метрика и оценка

### PSNR (Peak Signal-to-Noise Ratio)

Метрика качества — **PSNR** между предсказанным и GT изображением:

$$
\text{PSNR} = 20 \cdot \log_{10}\left(\frac{255}{\sqrt{\text{MSE}}}\right)
$$

где MSE — среднеквадратичная ошибка по всем пикселям и каналам:

$$
\text{MSE} = \frac{1}{H \times W \times 3} \sum_{i,j,c} \left( \text{pred}_{i,j,c} - \text{gt}_{i,j,c} \right)^2
$$

Оба изображения сравниваются как **uint8 RGB** (значения 0–255).

- Чем выше PSNR — тем лучше.
- Типичные значения: 15–20 dB для наивных бейзлайнов, 25–35 dB для хороших моделей.
- При идеальном совпадении (MSE = 0) PSNR = ∞.

### Итоговый скор

Итоговый скор = **средний PSNR** по всем тестовым сэмплам.

Тестовые сэмплы разделены на две группы:
- **Public** (видны на лидерборде во время соревнования)
- **Private** (скрыты, используются для финального ранжирования)

### Вердикты

| Вердикт | Описание |
|---------|----------|
| **OK** | Предсказание найдено, формат корректен, PSNR посчитан |
| **WrongAnswer** | Файл `pred.jpg` не найден для данного сэмпла |
| **PresentationError** | Файл не читается как изображение или размер не совпадает с GT |
